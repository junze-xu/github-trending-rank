> 🚧 全新项目（2026-11-07 起）：由旧版 GitHub Trending Archive 整体重建——旧版的 33 份手工报告与名称级历史归档已全部废弃。新站从今日起重新采样，周 / 年排行全部由增量指标驱动。

## 定位

| | |
|---|---|
| 📅 **周排行** | 本周新增 Star / Fork / 提交最多的项目 |
| 📆 **年度排行** | 全年累计增长、在榜次数最多的项目 |
| 🧭 **维度筛选** | 语言、分类、新老项目 |
| 🤖 **JSON API** | 公开数据出口，对齐 grok-bot-cn 体系规范，供 Bot / 其他页面消费 |

## 核心指标（只看"变化量"，不看历史总量）

- **Star / Fork 差分**：日前值、7 日 / 30 日增量与增速（增量 ÷ 当前总量）
- **提交趋势**：周 / 月提交数变化（GitHub API）
- **在榜连续性**：连续在榜天数、首次上榜、回归
- **聚合视图**：语言榜、分类榜（AI / Agent、前端、DevOps…）
- 老项目**历史总量再大也不占优**——榜单由增量决定，语言是维度之一

## 数据流

```
每日快照（src/ 采集器，完整卡片元数据）
     ↓ 跨天差分
周 / 月 / 年指标（derived 层）
     ↓ LLM 加工
分类标签与当日要点（editorial 层）
     ↓ 渲染
新站点页面 + JSON API（深色、零依赖、grok-bot-cn 同设计语言）
```
